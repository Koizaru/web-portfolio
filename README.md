nacuaaa website portfolio

Folder layout:
  index/index.html   Main page
  css/style.css      Medieval theme, responsive layout, CSS animations
  js/script.js       Navigation, reveal animations, profile/skills/projects editor

To run:
1. Extract the ZIP and keep all folders in their current locations.
2. Open index/index.html in a browser, or open the project folder in VS Code and use Live Server.
3. Click “Edit portfolio” in the lower-right corner to update your profile, add/delete skills, and add/delete projects.
4. Replace the sample email with your own before publishing.

Edits are saved to localStorage in the current browser on this device. They do not edit the source files or automatically sync to another device/hosted copy. Google Fonts requires internet access; fallback fonts are included.
